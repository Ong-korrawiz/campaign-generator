# ผลตรวจ prototype รอบหนึ่งวัน — 27 กันยายน 2026

## การเปลี่ยนแปลง

- ทดสอบและใช้ `guided_json` ของ vLLM 0.8.5 เพื่อบังคับฟิลด์ของ `CampaignDirectionV2` และจำกัดค่า channel ให้ตรงกับ brief
- ส่งข้อมูลไอเดียก่อนหน้าให้ prompt, ตรวจชื่อที่ใกล้เคียง, retry ได้สูงสุด 3 ครั้งต่อ concept และเติมประโยคที่อิงช่องทางเมื่อคำบรรยายมีเพียงหนึ่งประโยค
- ปรับหน้า demo เป็นฟอร์ม brief และแสดง concept, message, channel, asset, KPI และงบในรูปการ์ด

## ผลทดสอบ Public API

ใช้ holdout synthetic 20 briefs แบบวนตามอุตสาหกรรมรวม 9 อุตสาหกรรม; 10 brief มีช่วงงบและอีก 10 ไม่มีงบ ทั้งหมดเรียก `POST /generate` ผ่าน URL สาธารณะจริง

| เกณฑ์ | ผล |
| --- | ---: |
| HTTP 200 พร้อม 3 concepts ผ่าน schema | 20/20 |
| ชื่อ concept ไม่ซ้ำหรือคล้ายกันตามตัวตรวจ | 20/20 |
| คำบรรยาย 2–3 ประโยค, channel และงบผ่านกฎ | 20/20 |
| เวลา median / p95 ขณะ inference อุ่นอยู่ | 17.2 / 18.9 วินาที |
| ชื่อไอเดียที่มีเพียงคำเดียว | 25/60 concepts |
| Brief ที่ key message ซ้ำกันแบบตรงตัว | 3/20 |

ก่อนเติมประโยคคำบรรยาย รุ่นที่บังคับ schema ผ่าน 15/20 โดยทั้ง 5 ที่ไม่ผ่านติดจำนวนประโยค ผล 20/20 เป็นการทดสอบรูปแบบ ไม่ใช่การรับรองความคิดสร้างสรรค์หรือความถูกต้องของข้ออ้าง

การอ่านด้วยคน 5 brief แรกพบข้ออ้างที่ brief ไม่ยืนยัน เช่นส่วนลด ประหยัดเงิน และความสามารถสินค้าเพิ่มเติมในหลาย concepts จึงยังควรแสดงผลเป็น **ร่างสำหรับตรวจทาน** หน้า demo มีข้อความเตือนให้ตรวจข้ออ้างและ brand fit ก่อนใช้จริง

## ผลทดสอบ LoRA

ใช้ adapter เดิมกับ validation 6 briefs (เดิม 3, synthetic 3) ส่ง prompt แบบฝึกตรง ๆ และสุ่มคำตอบได้สูงสุด 6 ครั้งต่อ brief ผลคือ 6/6 briefs มี 3 concepts ที่ผ่าน schema, ใช้ช่องทางตาม brief และชื่อไม่ซ้ำแบบตรงตัว แต่เมื่อเพิ่มเกณฑ์คำบรรยาย 2–3 ประโยคและชื่อที่ไม่ใกล้เคียง เหลือ 3/6 briefs มีคำบรรยายผิดความยาว 6/18 concepts และชื่อใกล้เคียงกันอย่างน้อยหนึ่งคู่

ผลนี้แสดงว่าการใช้ prompt แบบฝึกช่วยให้ adapter สร้าง candidate ได้ แต่ยังไม่ยืนยันว่าไอเดียต่างกันเชิงความหมายหรือดีพอให้เป็นรุ่นหลัก จึงยังคง baseline ใน Public API

ไฟล์ผลอยู่ใน `experiments/public-api-20.json` และ `experiments/runs/schema-only-seed42-20260927/lora-three-concepts-v1.jsonl` โดยมีผลต้นฉบับบน GCS ส่วนตัวด้วย
